# 2026-11-13

## Zsh vi mode: cursor shape follows the keymap

The shell cursor now changes shape with the vi keymap, the same way Neovim does. Insert mode shows a beam, normal and visual mode show a block, and replace mode shows an underline.

`bindkey -v` was already set at `.zshrc:284`, but nothing told the terminal which mode the shell was in. The fix is a `zle-keymap-select` widget that prints the DECSCUSR escape for the current `$KEYMAP`, plus a `zle-line-init` widget that resets to a beam at each new prompt, and a `preexec` hook that hands a block to external commands such as `nvim` and `less`.

| Keymap | Shape | Escape |
| --- | --- | --- |
| `viins`, `main` | beam | `\e[6 q` |
| `vicmd` | block | `\e[2 q` |
| `visual` | block | `\e[2 q` |
| `viopp` | block | `\e[2 q` |
| replace (`$ZLE_STATE` contains `overwrite`) | underline | `\e[4 q` |

No terminal or tmux change was needed, which was the main thing to check:

- Ghostty's terminfo already defines `Ss=\E[%p1%d q` and `Se=\E[2 q`, so tmux detects cursor-style support on its own. `tmux display-message -p '#{client_termfeatures}'` already listed `cstyle`.
- `.config/ghostty/config` already sets `shell-integration-features = no-cursor`, so Ghostty's shell integration does not fight the manual escapes.

Two things to remember:

- The widget must be defined before `starship init zsh` at `.zshrc:474`. Starship does not replace an existing `zle-keymap-select`; it reads the old one into `__starship_preserved_zle_keymap_select` and wraps both in `starship_zle-keymap-select-wrapped`. Define the widget after Starship and Starship wins, which also breaks nothing visibly, so the failure is easy to miss. Verified after the change: the preserved name is `zle-keymap-select`, and the `N:`/`I:` prompt symbols still work.
- `viopp` is a block here. Neovim draws operator-pending as a half-height horizontal bar (`o:hor50`), and a terminal cursor has only three shapes, so there is nothing closer.

`~/.zshrc` is already a symlink into this repository, so no re-stow was needed.
