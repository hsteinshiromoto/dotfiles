# 2026-11-27

## Atuin history became a sesh session picker

The ask was to connect atuin to sesh. sesh accepts input from four places only: running tmux sessions, `[[session]]` blocks in `sesh.toml`, a frecency backend, and tmuxinator. There is no plugin hook. atuin accepts no external input at all. So every possible link is either atuin reading out into a sesh input, or a sesh session scoping an atuin filter.

Measurement killed the obvious link before it was built. Feeding atuin's directories to sesh, whether through a `[frecency]` backend or an extra television source, gains nothing: atuin holds 185 unique directories, zoxide 220, and only 5 of atuin's are absent from zoxide. Those 5 are `~`, `.config/glab-cli`, `nix/result`, a `.cursor/extensions` path and `Notes/02_Calendar/Daily_Notes`. Sync would have been the argument for atuin, because zoxide does not sync and atuin does, but this account does not sync. zoxide is a superset by construction.

What survived is the link neither tool has: pick a past command, open a session in the directory that command ran in.

## The channel

`.config/television/cable/atuin.toml` sources `atuin search --filter-mode global --format '{directory}\t{command}' --print0 --limit 2000 ''` and pipes it through `tr '\n\0' ' \n'`. The `--print0` matters. History holds `python -c` heredocs that span many lines, and without a NUL record terminator each one becomes a dozen broken rows. With it, `tr` can flatten the newlines inside a record and promote the NUL to the row separator.

`display` shows the command then its directory, `output` is the directory, the preview is `sesh preview`, and Enter runs `sesh connect` on the directory. `.tmux.conf` binds `prefix + a` to a popup running `tv atuin`, next to the `prefix + Space` popup that runs `tv sesh`.

### What was verified, and how

Television cannot template a source command, because no entry exists when the source runs, so atuin's `{directory}` and `{command}` reach atuin unexpanded. The official `docker-images` channel relies on the same thing to pass Go templates such as `{{.Repository}}` through. The behaviour was then confirmed directly: the channel returns real directories.

`tv --take-1` takes the first entry once the channel has loaded and prints it, which makes a television channel testable without a terminal. Wrapped in `perl -e 'alarm 10; exec @ARGV'` it cannot hang. `tv atuin --take-1` returned `/Users/hsteinshiromoto/Projects/tmp/kg/graphrag-local`.

The two spellings of a tab in a split template, `"{split:\t:0}"` and `"{split:\\t:0}"`, both work on television 0.15.6; the cable files already in this repository disagree with each other on this point and neither is wrong.

### What was left out

The connect action does not pass `-c '{split:\t:1}'` to re-run the chosen command on a new session. Recorded commands routinely contain single quotes, which would break the quoting and hand a mangled command to the shell. After connecting, the same command is one `Ctrl-R` away, already scoped to that directory by `filter_mode = "directory"`.

Directories that no longer exist are still listed; 21 of atuin's 185 are gone. `sesh` fails on them rather than hiding them, which is the cheaper behaviour until it is annoying.
