# 2026-11-05

## Design-thinking agent team: template, spawnable facilitator, vault symlink

Added `.claude/templates/DesignThinkingTeam.md` (v2), a system prompt that runs the Stanford d.school 5-stage process (Empathize, Define, Ideate, Prototype, Test) by orchestrating Claude Code subagents. The prompt was produced by an 11-agent workflow (3 angled drafts, 3 judges, synthesis, 3 adversarial critics, fix pass; 17 blocker/major findings fixed), then refined through a grilling session. Key decisions from that session:

- Standalone process — it does not feed the PM/Architect/QA/Developer workflow.
- Lite tier is the default (1 researcher, 2 ideators, 1 curator, 1 prototyper, 2 persona testers, 1 critic; 1 iteration loop). Full tier (3 researchers, 4 ideator lenses, tester per persona, 2 loops) needs gate approval.
- "Ship" is forbidden on SIMULATED-only evidence; a passing simulated test caps at "proceed to real-user validation".
- Artifacts land in `<project>/design/`; inside an Obsidian vault they go to `05_Spaces/<Project>/design/` with vault frontmatter.

Added `.claude/agents/design_thinking_facilitator.md`, a thin bootstrap that Reads the template as its operating manual, so `design-thinking-facilitator` is a spawnable agent type while the template stays the single source of truth.

Added the symlink `.claude/templates/agents -> ../agents`, which makes the agent definitions visible in the Notes vault at `_meta_/_templates_/claude/agents/` through the existing `claude` folder symlink. Nothing moved; `~/.claude/agents` is untouched.
